## Current status (0.4.1)

Structure: workspace with `apps/antirustpaste-macos`, `apps/antirustpaste-mcp`,
`apps/antirustpaste-linux`, `crates/antirustpaste-control`,
`crates/antirustpaste-core`, `crates/antirustpaste-imaging` and
`crates/antirustpaste-pdf`. macOS is the primary, fully exercised shell. The
Linux GTK4/X11 shell exists in the tree but was not run on this macOS host; see
[platforms.md](platforms.md).

Working: menu-bar app, text/RTF/HTML/image/file capture, Text/Images/Commands
tabs, on-demand zsh/bash history, pure-Rust thumbnails, Quick Look for every
clip kind, in-app text editing and Quick Look → TextEdit import, dedup, search,
keyboard navigation, ⌘1…⌘9 quick paste, paste, pinned clips, custom clip
titles, row context menu, status menu, pause/resume recording, tab-scoped
**Clear All** / **Clear Unpinned**, Preferences **History** tab with scoped
deletes and disk usage, preferences, ignored apps, history limits, login item,
global shortcut, launch/About release check with in-place update and restart. A
bundled MCP bridge controls the running app through a private loopback HTTP
endpoint; see [mcp.md](mcp.md).

Known gaps: no per-row accessibility elements in the hand-drawn list, no image
grid, EXIF orientation is not applied, RTFD previews fall back to plain text and
HTML previews are rendered by the system panel (which may load referenced remote
resources), editing is limited to text/command clips up to 1 MiB, the Quick
Look → TextEdit round-trip depends on the system Open-with button, no
encryption, no schema migration yet
(the format is version-less JSON). Shell commands appear only after the shell
writes its history file and the tab is refreshed; a custom `$HISTFILE` and fish
history are not read. Thumbnails are generated by one background worker and
cached under `/tmp` on macOS (boot-cleared). The Linux shell lacks MCP control,
the scoped clear actions and the tray recording toggle.
