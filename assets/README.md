# Assets

- `app-icon/source.png` — the highlighter-and-check icon supplied by the project
  owner on 2026-11-25. It is project artwork, not copied from another product.
- `app-icon/AppIcon-1024.png` — the square master derived from `source.png`.
- `app-icon/AppIcon.icns` — macOS bundle icon generated from the master.
- `status-icon.png` — a 36 px monochrome template derived from the same source,
  used for the menu bar; white areas are cut out so the checkmark shows through.

- `dmg/background.png` and `dmg/background@2x.png` — the neutral background with
  a dashed arrow used by the disk image window. Drawn in-house with CoreGraphics
  on 2026-11-25 for this project; no third-party artwork.

When regenerating the icon or the disk-image background, keep the same
provenance and update this file.
