## Current status (0.2.1)

Structure: workspace with `apps/antirustpaste-macos`, `crates/antirustpaste-core`,
`crates/antirustpaste-imaging` and `crates/antirustpaste-pdf`. Only macOS is implemented; see
[platforms.md](platforms.md).

Working: menu-bar app, text/RTF/HTML/image/file capture, Text/Images tabs,
pure-Rust thumbnails, dedup, search, keyboard navigation, paste, status menu,
preferences, ignored apps, history limit, login item, global shortcut.

Known gaps: no per-row accessibility elements in the hand-drawn list, no image
grid, EXIF orientation is not applied, no encryption, no schema migration yet
(the format is version-less JSON). Thumbnails are generated by one background
worker and cached under `/tmp` on macOS (boot-cleared).
